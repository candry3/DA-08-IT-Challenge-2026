Technical Approach

What the Prototype Actually Does

Six source data files from the case → one single-file HTML prototype. No backend. No login. Opens in any browser.

Data sources used

student.csv older_transcript.csv
program_requirements.csv course_mapping.csv
holds.csv spring_2027_schedule.csv

The matching engine

1. Apply course equivalency rules (IVYT 101 → IVYT 111; BUSN 210 → BUSN 211)
2. Match transcript courses to program requirements by exact course ID
3. Flag Withdrawals (W) as not satisfying requirements → retake required
4. Identify elective slots and fill with unused passing credits
5. Flag courses not in selected program as extra (useful for other credentials)

Three programs from source data

Business Administration (AAS) · 60 cr.
Business Operations (Certificate) · 18 cr.
Human Resources (Tech. Cert.) · 15 cr.
