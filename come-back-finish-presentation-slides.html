The matching engine

1. Apply course equivalency rules (IVYT 101→111; BUSN 210→211)
2. Match by exact current course ID
3. Flag Withdrawals (W) — does not satisfy a requirement
4. Fill elective slots with unused passing credits
5. Cross-reference Spring 2027 schedule vs. work hours

Part 3 · The Roadblock 20 points
Part 3 · The Roadblock — 20 pts

Three Findings. All Three Addressed.

Pilot feedback from Renee's persona. Rubric requires at least two of three addressed inside the existing build — no restart. We addressed all three.

🕐 Finding 1 — "This assumes I can attend full time"
Problem: Original hero stat showed "~2 semesters (full-time)" — meaningless for someone working Mon–Fri 8–4:30.
Changes made: Hero now shows part-time semesters as the primary number · Finding 1 retitled "This Plan Works Around Your Job" · Amber alert explicitly states online/evening only · Full-time flagged as not recommended · Spring 2027 table shows ✓/✗ per section vs. work hours
🏁 Finding 2 — "Show me the shortest path to finishing"
Problem: Finding 2 was collapsed by default and buried — the certificate path wasn't prominent enough.
Changes made: Finding 2 now opens by default · Dynamic headline: "Renee Already Qualifies for the Business Operations Certificate" · Green success alert leads: "Renee can earn a credential this semester" · Each credential shown as a card sorted by % complete · States zero duplication with the AAS
🔒 Finding 3 — "I have a hold on my account"
Problem: Two holds in the data — but not prominent enough. A student might miss them before trying to register.
Changes made: Danger alert leads with "Your credits are safe" · Both holds surfaced on the Transcript screen before the audit runs · Step-by-step "Clear in this order" box · Specifically calls out the Returning Student Balance Forgiveness Program before paying · Closes: advisors can start before holds are cleared
🎙 Talk Track (~40 sec) Three findings came back. Finding 1: assumes full-time — we made part-time the headline and flagged every section against her work hours. Finding 2: show the shortest path — Finding 2 now opens by default with "Renee can earn a credential this semester." Finding 3: the hold — we surface both holds before she even runs the audit, with a step-by-step clear order and a note to ask about the Balance Forgiveness Program before paying anything.

2030 Impact Statement

Who benefits

Every Ivy Tech stop-out student — especially working adults, single parents, and low-income learners who can't afford the time cost of the old appointment-dependent process.

Which metric moves, by how much

Stop-out credential completion rate. 1,000/year by 2030. Tool removes the decision barrier — the moment Renee thinks "I don't know where to start" and closes the tab.

What rollout takes across Ivy Tech

SIS integration for real transcripts · Program catalog data feed · A-IVY advising layer · Proactive text outreach to every stopped-out student

The one risk we'd watch

Over-reliance on self-service — a student who sees "100% done" may skip formal readmission steps. Mitigation: every screen surfaces a human advisor path and the holds check.
